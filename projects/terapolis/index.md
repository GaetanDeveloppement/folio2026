Terapolis est une entreprise française spécialisée dans le développement et le déploiement de projets d'énergies renouvelables sur les territoires ruraux ; agrivoltaïsme, stockage d'énergie, robotique agricole. Ils accompagnent agriculteurs et collectivités en co-construisant des projets qui allient production agricole, bien-être animal et performance énergétique.

J'ai été contacté par <a href="https://www.noesya.coop/" target="_blank">noesya<a/> pour la création d'un site web WebGL, pensé pour présenter de manière interactive leurs différents modules d'activité sur tablette tactile lors de salons.
